# Bottleneck Service Results

This folder stores bottleneck-service targeting evaluation outputs.

Run:

```bash
bash src/scripts/bottleneck_service/run_bottleneck_service.sh all observation
```

Outputs:

- per case under `results/bottleneck_service/<case-name>/`
- phase summary files:
  - `results/bottleneck_service/phase_summary.json`
  - `results/bottleneck_service/phase_summary.md`

Do not create new placeholder subfolders here. Keep each phase under its real output root.
