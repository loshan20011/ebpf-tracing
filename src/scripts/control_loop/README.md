Control-loop scripts:

- `run_control_loop_phases.sh`: run one or all control-loop cases.
- `run_control_loop_case.py`: execute a single control-loop case.
- `summarize_control_loop_case.py`: summarize a single case.
- `summarize_control_loop_phase.py`: summarize a phase directory.
- `cases/`: control-loop case definitions.

Example:

```bash
bash src/scripts/control_loop/run_control_loop_phases.sh CL2_sustained_increase
```
