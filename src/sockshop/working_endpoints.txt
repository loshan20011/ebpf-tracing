GET /login is not a usable public load route in this deployment

the clean API routes we can rely on are mainly:
/catalogue
/cart
Best practical choice now:

use /cart for downstream-path tests
keep /catalogue as a secondary reference only if we specifically want to study slow rollout behavior
do not use /login unless we implement a proper authenticated flow
